## Foundation

- **Форм-фактор:** вебзастосунок, mobile-first (регулярний донор відкриває нагадування з телефона), повноцінний десктоп.
- **UI-система:** Bootstrap 5.3 (SCSS + `bootstrap.bundle` для dropdown/collapse). Цей документ описує лише поведінкову дельту поверх Bootstrap.
- **Візуальна ідентичність:** `DESIGN.md`. Токени посилаються як `{colors.primary}` тощо.
- **Інваріант редизайну:** функціональна поведінка, API-виклики, маршрути, Redux-стан і типи — без змін. Змінюється лише розмітка, стилі та суто візуальний відгук.

## Information Architecture

Маршрути не змінюються. Нові лише презентаційні обгортки.

| Маршрут | Поверхня | Що змінюється візуально |
|---|---|---|
| `/patronage_of_military_units` | Головна | Hero з логотипом + CTA; «Як це працює» (3 кроки); сітка зборів |
| `/organizations` | Організації | PageHeader + сітка OrgCard |
| `/organizations/:id` | Організація | Шапка з обкладинкою-ініціалами, опис, сітка зборів організації |
| `/fundraisings/:id` | Збір | Дві колонки + липка панель дій; список джерел |
| `/login` | Вхід | Центрована картка з логотипом і кнопкою Google |
| `/my-subscriptions` | Мої підписки | PageHeader з поясненням + кабінетні картки |
| `/my-fundraisings` | Мої збори | PageHeader + кнопка «Додати збір» + кабінетні картки |
| `/my-organizations` | Мої організації | PageHeader + кнопка «Додати організацію» + кабінетні картки |
| `/add-…`, `/edit-…` | Форми | Картка-форма, фієлдсети джерел |
| `/redirect-bank-link` | Перехід | Спінер «Відкриваємо сторінку оплати…» |

**Глобальна оболонка (`PageLayout`):** Header (липкий) → `<main>` → Footer. Хедер: «Збори» (головна), «Організації», для авторизованого — «Профіль ▾» (Мої підписки / Мої збори / Мої організації) і «Додати ▾» (Збір / Організацію); «Увійти» / «Вийти».

## Voice and Tone

- Звертання на «ви», коротко, без пафосу й без вигуків у кожному реченні.
- Дієслова дії на кнопках: «Задонатити», «Підписатись», «Переглянути збори».
- Латинські рештки перекладаються: «Logout» → «Вийти», «Loading...» → «Завантаження…», «Redirecting...» → «Відкриваємо сторінку оплати…».
- Технічні повідомлення про помилки не показуються як є; тост: «Не вдалося завантажити дані. Спробуйте ще раз.» (текст з `errorSlice` лишається як деталь, якщо він людський).

## Component Patterns

- **Картка-посилання** (FundraisingCard, OrgCard): уся картка клікабельна і фокусована (`<button>`/`role="link"` + Enter), обробник — той самий, що зараз (`navigate(..., { state })`).
- **Кабінетна картка:** клік по тілу — перегляд; кнопки дій не спливають подію на картку.
- **Панель дій збору:** кнопки викликають ті самі `navigateToBankLink` і `handleSubscribe`.
- **Pagination:** та сама логіка `currentPage`, лише новий вигляд; при зміні сторінки — плавний скрол до початку сітки.
- **Header на мобільному:** `navbar-expand-lg` + collapse; закривається після вибору пункту.

## State Patterns

| Стан | Поведінка |
|---|---|
| Завантаження списку | 3–6 скелетон-карток замість порожнечі (поки масив порожній і запит не завершився) |
| Порожній список | EmptyState: «Тут поки порожньо» + доречна кнопка (напр. «Додати перший збір») |
| Завантаження деталей | Скелетон заголовка і панелі замість «Loading...» |
| Помилка | Тост ErrorAlert у правому нижньому куті, автозакриття 5 с (як зараз) |
| Підписка в процесі | Кнопка «Підписатись» — спінер, `disabled` |
| Підписка успішна | Кнопка → «Ви підписані ✓» (`{colors.teal}`), тост успіху; повторний клік неактивний до перезавантаження сторінки |
| Підписка з помилкою | Кнопка повертається у вихідний стан; помилка — як зараз (консоль) + тост |

> Стан «завантаження/порожньо» визначається локальним прапорцем у компоненті поруч з наявним `useEffect`; сам запит не змінюється.

## Interaction Primitives

- Наведення на картку: підйом 2px + тінь рівня 2, 180 мс `ease-out`.
- Натискання кнопки: затемнення на 1 крок (`-hover` токен), без зміни розміру.
- `prefers-reduced-motion` — анімації вимикаються.

## Accessibility Floor

- Усі клікабельні `<a>` без `href` → `<button type="button">` або `<Link>`.
- `alt` на всіх зображеннях; декоративні — `alt=""`.
- Видимий фокус на кожному інтерактивному елементі.
- Контраст тексту ≥ 4.5:1 (перевірено для пар у `DESIGN.md`).
- `<html lang="uk">`, осмислений `<title>`.
- Цілі натискання ≥ 44×44px на мобільному.

## Key Flows

### 1. Оксана, бухгалтерка, 34 — перша підписка з телефона
1. Бачить посилання у Facebook, відкриває головну на телефоні.
2. Перший екран: логотип, «Підтримуйте підрозділи регулярно» і жовта кнопка «Переглянути збори».
3. Гортає до сітки, бачить різнокольорові картки — «Аптечки IFAK» вирізняється медичним гліфом.
4. Відкриває збір: опис, організація, джерела оплати; знизу закріплена панель «Задонатити / Підписатись».
5. Вона ще не увійшла: зараз «Підписатись» для гостя мовчки нічого не робить. Пропозиція (Q4, на рішення власника): для гостя кнопка звучить «Увійти, щоб підписатись» і веде на `/login`. Оксана входить через Google і повертається на збір.
6. **Кульмінація:** тисне «Підписатись» — кнопка стає бірюзовою «Ви підписані ✓», з'являється тост. Вона розуміє, що 1-го числа їй нагадають.

### 2. Тарас, волонтер підрозділу — додає збір
1. Входить, «Додати ▾ → Збір».
2. Форма-картка: назва, опис, вибір організації, джерело №1 як окрема картка.
3. Заповнює перше джерело → з'являється «+ Додати ще одне джерело».
4. **Кульмінація:** «Зберегти збір» → потрапляє в «Мої збори», бачить свою картку з обкладинкою у фірмових кольорах.

### 3. Оксана, 1-ше число місяця — нагадування
1. Модалка «Час підтримати ваші збори» з логотипом.
2. «Перейти до підписок» → кабінет із жовтими кнопками «Задонатити» на кожній картці.
3. **Кульмінація:** один дотик — відкривається банка в новій вкладці.

## Responsive & Platform

- < 576px: 1 колонка; панель дій збору — фіксована знизу (дві кнопки поруч); hero — логотип над текстом, 200px.
- 576–991px: 2 колонки; хедер — бургер.
- ≥ 992px: 3 колонки; панель дій — липка праворуч.

## Поза межами (потребує рішення власника)

- Виправлення логічних багів (див. `REDESIGN-PLAN.md`, розділ «Баги логіки»).
- Підтвердження перед видаленням.
- Кнопка «Увійти, щоб підписатись» для гостя (зараз клік гостя ігнорується).
- Клікабельні посилання на кожне джерело оплати.
- Темна тема (токени готові до неї).
